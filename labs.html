Multi-Step Organic Synthesis & Process Chemistry

Continuous Synthesis Route Design

End-to-end design of multi-step synthesis routes optimized for continuous flow, pairing computational screening with process-level route evaluation before any bench work.

  • Computational screening — DFT (ORCA) and semi-empirical GFN2-xTB for rapid thermodynamic and reactivity ranking of candidate routes and intermediates.
  • Route evaluation framework — scored decision matrix weighing yield, atom economy, step count, EHS, reagent cost, and flow compatibility.
  • Continuous-flow photochemical reactor — architecture for UV/VIS photochemistry in flow, addressing photon delivery, residence-time control, and scale-out.

Distillation Process Analysis System

White Mule — Real-Time Cut-Point Identification

A multi-sensor fusion instrument that identifies distillation cut-points in real time, removing the guesswork from batch distillation.

  • Multi-sensor fusion — refractive index, temperature, and conductivity signals fused into a continuous phase/composition estimate.
  • Real-time cut-point detection — automated heads / hearts / tails transitions flagged live during a run.
  • Sub-$100 BOM — commodity sensors and a microcontroller keep the bill of materials under $100, a fraction of lab refractometer cost.

Morgul / Silmaril

USB Physical Passkey Generator

A hardware security token that derives deterministic passwords from a master secret using HMAC — a physical key to a password vault that never stores the passwords themselves.

  • Deterministic HMAC generation — passwords derived from (secret × domain) so nothing sensitive is ever persisted on the device.
  • USB form factor — self-contained token that types credentials directly, no host-side software trust required.
  • Physical passkey — a tangible root-of-trust object for high-value accounts.
